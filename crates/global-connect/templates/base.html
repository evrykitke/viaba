{# The document. Everything the site serves is this file with a body in it. `data-theme="dark"` is written here rather than left off, and that is the one place this crate deliberately disagrees with Desk. Desk omits the attribute so a visitor's operating system decides, because Desk is a tool somebody keeps open all day beside other windows. This is a front page: it is one composition with artwork in it, and a composition that renders two ways is two compositions to keep good. Dark is the one it is designed as. `data-accent="violet"` for the same reason - the product lets a workspace pick an accent and there is nobody here to pick one, so the site wears the default. `lang` and `dir` come from the language in the address, not from a header. A wrong `lang` is what makes a screen reader pronounce Chinese as English, and `dir` is carried even though both languages here run left to right - the product's own reasoning, which is that retrofitting it after the markup exists is the expensive version. The `hreflang` links declare one address per language, which is how a search engine is told these are translations of each other rather than duplicates. `x-default` points at English, which is what a crawler with no preference should be sent to. Two requests make a page: one stylesheet and one script, both with a content hash in the name, so both are cached forever and neither can be stale. The script is `defer`red because nothing waits for it - see `script/site.js`. The policy in `routes::html_response` is `script-src 'self'` with no `unsafe-inline`, so the only code that runs here is code this binary served. The favicon is a data URI, not a file. This crate ships no image at all: the artwork is inline SVG, which is markup rather than a request. #} {% block title %}{% endblock %} — {{ frame.product_name }} {% for alternate in frame.languages %} {% endfor %} {{ t.common.skip_to_content }} {% include "_nav.html" %}
